# Personal Dashboard

Este Dashboard foi projetado para impulsionar a produtividade no dia a dia, integrando de forma prática ferramentas simples e amplamente utilizadas.

Na sua construção, foram empregadas as tecnologias HTML, CSS e JavaScript, com o suporte do framework React. Este projeto marcou o ponto de partida da minha jornada de aprendizado em React, permitindo consolidar conhecimentos fundamentais e explorar suas capacidades na criação de interfaces dinâmicas e eficientes. Abaixo irei deixar algumas imagens das funcionalidades presentes (algumas ainda serão desenvolvidas futuramente).
